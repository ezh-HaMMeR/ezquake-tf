Настройки освещения и обводки теперь используют общие категории моделей. Можно оставить свет карты для построек, отдельно выделить гранаты и предметы, либо настроить обводку только игроков.

## Новые возможности

### Общие категории моделей

| Категория | Состав |
|---|---|
| `players` | Игроки, трупы, обезглавленные тела, головы и части тел |
| `grenades` | Гранаты, детпак, дочерние заряды MIRV, шипы и сигнальная граната |
| `buildings` | Сентри всех уровней, станина, диспенсер, Tesla и обломки построек |
| `projectiles` | Ракеты, гвозди и крюк; общий гвоздь Nail-гранаты и гвоздомёта относится сюда |
| `pickups` | Модели оружия, брони, бонусов, рюкзаков, аптечек и ящиков боеприпасов |
| `objectives` | Известные клиенту флаги, ключи и модели предметов заданий |
| `props` | Остальные модели MDL/MD3, в том числе декор; неизвестные клиенту модели попадают сюда |

Категории определяются по назначению сущности, известным именам и типам моделей, независимо от PAK или отдельных файлов. Пользовательские предметы с неизвестным именем могут попасть в `props`.

### Фильтр освещения

`gl_fb_tfmodels_filter` инвертирует `gl_fb_tfmodels` для перечисленных категорий. Названия разделяются пробелами или запятыми, регистр не важен. Неизвестные слова игнорируются; пустая строка `""` означает отсутствие исключений.

| `gl_fb_tfmodels` | Категория вне фильтра | Категория в фильтре |
|---|---|---|
| `0` | Свет карты и динамических источников | Обычные настройки fullbright |
| `1` | Обычные настройки fullbright | Свет карты и динамических источников |

Обычные настройки fullbright — это существующие `gl_fb_models`, `r_fullbrightSkins` и настройки конкретных моделей с сохранением ограничений сервера и ruleset. Фильтр не включает безусловное свечение и не обходит серверный предел яркости игроков.

Значения по умолчанию:

```cfg
gl_fb_tfmodels 0
gl_fb_tfmodels_filter "players pickups objectives props"
```

Игроки, предметы, флаги и декор сохраняют обычные настройки. Постройки, гранаты и снаряды используют свет карты. По сравнению с предыдущим выпуском обычное освещение теперь распространяется и на ракеты.

Пример: свет карты только для построек и гранат, остальные категории по обычным настройкам:

```cfg
gl_fb_models 1
gl_fb_tfmodels 1
gl_fb_tfmodels_filter "buildings grenades"
```

Пример: все поддерживаемые категории используют свет карты, включая игроков:

```cfg
gl_fb_tfmodels 0
gl_fb_tfmodels_filter ""
```

Пример: вернуть поведение общих настроек для всех категорий:

```cfg
gl_fb_tfmodels 1
gl_fb_tfmodels_filter ""
```

### Четыре группы обводки

Добавлены `gl_outline_group1`–`gl_outline_group4`. Каждый слот объединяет любое количество категорий и имеет отдельные параметры:

| Команда, где N = 1–4 | По умолчанию | Действие |
|---|---|---|
| `gl_outline_groupN` | `""` | Список категорий; пустой слот не используется |
| `gl_outline_groupN_color` | `"0 0 0"` | Цвет RGB, каждый канал 0–255 |
| `gl_outline_groupN_scale` | `1` | Толщина 0–5; дробные значения допустимы, 0 скрывает обводку |
| `gl_outline_groupN_enable` | `1` | 0 отключает обводку объектов этого слота, 1 включает |

Работает в классическом и современном OpenGL, для MDL и MD3. В ограниченных ruleset толщина ограничивается 0–1; запреты обводки сохраняются. Толщина — коэффициент геометрического расширения, а не число пикселей; её вид зависит от модели и рендерера.

Главный переключатель — `gl_outline`: 0 отключает обводку, 1 включает модели, 2 только геометрию карты, 3 модели и геометрию. Группы не включают обводку при `gl_outline 0` или `2`.

Если категория указана в нескольких слотах, побеждает первый по номеру, даже если он отключён. Объекты, не попавшие ни в один слот, сохраняют прежнюю общую обводку. Цвет назначенного слота заменяет общие и командные цвета обводки; пустые слоты сохраняют существующее поведение, включая глобальные настройки цветов игроков современного рендерера.

Пример: гранаты, предметы и флаги оранжевые, постройки голубые, игроки зелёные, снаряды и декор без обводки:

```cfg
gl_outline 1

gl_outline_group1 "grenades pickups objectives"
gl_outline_group1_color "255 160 30"
gl_outline_group1_scale 1.2
gl_outline_group1_enable 1

gl_outline_group2 "buildings"
gl_outline_group2_color "60 170 255"
gl_outline_group2_scale 0.8
gl_outline_group2_enable 1

gl_outline_group3 "players"
gl_outline_group3_color "80 220 100"
gl_outline_group3_scale 0.5
gl_outline_group3_enable 1

gl_outline_group4 "projectiles props"
gl_outline_group4_enable 0
```

Пример: только игроки, их трупы и части тел; замена удалённой `gl_outline_onlyplayers`:

```cfg
gl_outline 1
gl_outline_group1 "players"
gl_outline_group1_color "80 220 100"
gl_outline_group1_scale 0.7
gl_outline_group1_enable 1
gl_outline_group2 "grenades buildings projectiles pickups objectives props"
gl_outline_group2_enable 0
gl_outline_group3 ""
gl_outline_group4 ""
```

Пример: сохранить прежние командные цвета игроков, скрыв обводку остальных категорий:

```cfg
gl_outline 1
gl_outline_group1 "grenades buildings projectiles pickups objectives props"
gl_outline_group1_enable 0
gl_outline_group2 ""
gl_outline_group3 ""
gl_outline_group4 ""
```

Вернуть прежнюю общую обводку без групповых переопределений:

```cfg
gl_outline_group1 ""
gl_outline_group2 ""
gl_outline_group3 ""
gl_outline_group4 ""
```

После настройки можно сохранить конфигурацию командой `cfg_save`.

## Исправления

- В классическом режиме без шейдеров цвет обводки больше не умножается на текстуру модели. Для MD3 в этом режиме добавлен учёт освещения при выборе света карты через новый фильтр.

## Совместимость

- Удалена `gl_outline_onlyplayers`: старую строку следует убрать из конфигурации и заменить приведённым выше групповым примером.
- Фильтр освещения применяется только в Team Fortress. Группы обводки применяются к распознанным моделям и в других режимах игры.
- Группы управляют моделями MDL/MD3. Стены, двери, платформы и предметы в формате BSP, спрайты и `r_simpleitems` используют другие пути отрисовки и не получают групповой стиль. Обводка геометрии карты остаётся под существующими настройками `gl_outline` и `gl_outline_*_world`.
- Оружие от первого лица и прикреплённое оружие игроков, глаза невидимого игрока, огонь и световые эффекты не включены в категории. Их существующее поведение сохраняется. Группы не добавляют обводку прозрачным моделям и не меняют наблюдательский X-ray.
- Светящиеся участки текстур и глобальный отладочный `r_fullbright` не отключаются фильтром освещения. Сервер и пакеты моделей менять не требуется.
